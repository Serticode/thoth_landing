# Thoth landing page

Landing page for [Thoth](https://thoth.serticode.com): an identity preserving publishing engine for engineers who write.

## Tech stack

- **HTML** semantic, accessible markup
- **CSS** custom properties, component driven, no frameworks
- **JavaScript** vanilla, lightweight interactions
- **Hosting configuration** Cloudflare Workers static assets

The site has no build step. `index.html` contains the landing page, `docs.html` contains the CLI documentation, and `css/` and `js/` contain the styles and interactions.
